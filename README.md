A developer-facing component library built to be called in as few lines as possible: sensible defaults mean common cases need no boilerplate (FutureText("My Text")), first parameters are deliberately chosen to avoid naming arguments, and modifiers are kept cleanly separated from components. Theming runs through CompositionLocal with 10+ curated palettes plus support for per-app custom themes. Includes 50+ icons drawn entirely with Canvas primitives - no image assets, fully tintable, fully themeable. Powers the interface of all other Kotlin apps below.
